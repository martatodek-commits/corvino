# Corvino — strona pod GitHub Pages

Gotowy statyczny projekt:

- `index.html` — strona główna Corvino
- `style.css` — cały wygląd + responsywność
- `script.js` — menu mobilne i rok w stopce
- `ksef-segregator/index.html` — długa podstrona aplikacji z sekcjami:
  - dane do App Store Connect
  - Support
  - Privacy Policy
  - Terms
  - usunięcie konta/danych
  - kontakt

## Ważne

Pola oznaczone `UZUPEŁNIJ` trzeba uzupełnić przed publikacją aplikacji.
Szczególnie dotyczy to polityki prywatności, sposobu przechowywania danych,
modelu płatności oraz procedury usunięcia konta.

## GitHub Pages

Po wrzuceniu plików do repozytorium:

1. GitHub → repozytorium `corvino`
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: `main` / folder `/ (root)`
5. Save

Po uruchomieniu Pages strona będzie dostępna pod adresem GitHub Pages.
Następnie można podpiąć `corvino.pl` jako Custom domain.
